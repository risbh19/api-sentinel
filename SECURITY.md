# Security

Please contact the repository owner, @risbh19, before sharing sensitive details. Collaborators can open an issue requesting a private disclosure channel with just a contact handle and the affected version. The owner can then arrange a private exchange. Keep credentials, customer telemetry and proof material out of issues, pull requests and logs.

This milestone supports local development. The liveness endpoint returns a fixed process status and accepts no application data. Access logging is disabled in the documented launch commands because URLs can contain private values. Tests use synthetic inputs. Any future change that collects telemetry must document accepted fields, tenant scoping and retention.
