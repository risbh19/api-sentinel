# Contributing

Branch from the current main revision. Use a short kebab-case branch and
imperative sentence-case commits. Open one pull request per testable feature
with the actual changes, commands, results and outstanding checks.

Run the checks and Compose smoke procedure in the README. Review the diff,
privacy impact, required approvals and checks before using a GitHub merge
commit. Record any skipped or unavailable check explicitly. Hosted CI for
this private repository requires a confirmed billing configuration.
